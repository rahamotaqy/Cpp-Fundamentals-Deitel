# Chapter 16 — Exception Handling

Exercises covering C++ exception handling and smart-pointer memory management.

| Exercise | What it demonstrates |
|---|---|
| `exercise_16.auto_ptr` | A custom exception class and `std::unique_ptr` for automatic memory cleanup. The original C++98 `auto_ptr` was modernized to `unique_ptr` because `auto_ptr` was removed in C++17. |
