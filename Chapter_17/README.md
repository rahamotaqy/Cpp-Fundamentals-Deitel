# Chapter 17 — File Processing

Exercises covering sequential and random-access file processing with `fstream`.

| Exercise | What it demonstrates |
|---|---|
| `exercise_17.file_stream_basics` | Sequential text-file read/write/append with `fstream`. |
| `exercise_17.random_access_file` | Three cooperating programs for random-access file management. |
| `exercise_17.random_access_file/create_blank_records` | Creates a binary file with 100 blank `ClientData` records. |
| `exercise_17.random_access_file/write_records` | Writes user-entered records into the random-access file. |
| `exercise_17.random_access_file/transaction_control` | Menu-driven program to print, update, insert, and delete records. |

The random-access programs share a single portable `client_data.hpp`.
