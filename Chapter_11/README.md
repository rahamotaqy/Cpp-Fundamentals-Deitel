# Chapter 11 — Operator Overloading

Exercises that overload operators to make user-defined types behave like built-in types.

| Exercise | What it demonstrates |
|---|---|
| `exercise_11.array_class` | A custom `Array` class with overloaded `<<`, `>>`, `==`, `!=`, `=`, `[]`, etc. |
| `exercise_11.array_test` | Driver program for the custom `Array` class. |
| `exercise_11.date_test` | A `Date` class with overloaded `++`, `+=`, `<<`, and `>>`. |
| `exercise_11.string_test` | A custom `String` class with relational and stream operators. |
